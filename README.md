# Looking Sketchy

**The Interactive Field Guide to Visual Thinking, Sketching & Non-Artist Illustration.**

Live site: **[davej91.github.io/lookingSketchy](https://davej91.github.io/lookingSketchy/)**

## What's Inside
- **18 Structured Chapters (`#ch1`–`#ch18`)**: Visual thinking & Gestalt principles, paper/ink physics, biomechanics of neat handwriting (with 10-symptom diagnostic & trace pad), hand-lettering hierarchy, real-time note compression, dot-grid charts, 3D primitives & perspective, light/shadow physics, visual storytelling, complex diagrams, and analog-to-digital workflows.
- **16 Interactive Studios (`#appA`–`#appP`)**:
  - **200-Illustration "Draw Anything in 4 Steps" School** (`#appD`) with live ghost trace pad, `★ Favorites`, and PNG export.
  - **200-Graphic Sketchnote Steal Book** (`#appC`) across 10 categories with progressive 3-step build reveals & Idea Generator.
  - **Exploded-View Isometrics Studio** (`#appK`) with live explode slider.
  - **Product Thinking & UX Sketching Studio** (`#appL`) with 4-state edge-case wireframes & live 2×2 prioritizer.
  - **Physical Hand Craft & Marker Restraint Handbook** (`#appM`) with Pass 1 → Pass 2 messy-call rescue & 5 marker palettes.
  - **Design Theory & Squint-Test Lab** (`#appN`), **Visual Learning & Retention Model** (`#appO`), **8 Illustration Styles Beyond Isometric** (`#appP`), **Clever Metaphors Atelier** (`#appJ`), **Mind-Map Studio** (`#appE`), **Accounting & Tax Notes** (`#appF`), **Process Flows** (`#appG`), **Language Notebook Studio** (`#appH`), **Analog Study Systems** (`#appI`), **Dissected Spreads** (`#appA`), and **8 Printable A5/A4 Vector Drill Sheets** (`#appB`).
- **Studio Features**: `⌘K` deep-link search across 500+ items, toggleable organic pigment **Ink Tooth** SVG filter, `★ Favorites` swipe file, local progress persistence + JSON import/export, and single-file offline build support.

## Local Development

```bash
npm install
npm run dev
```

## Build Standalone Single-File Bundle

```bash
npm run build
```

Outputs a self-contained `dist/index.html` via `vite-plugin-singlefile` that works offline in any modern browser.
